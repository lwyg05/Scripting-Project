# Inventory Management & Sales Analytics System

## Project Description

This project is a Python-based Inventory Management and Sales Analytics System developed for the Scripting Languages for AI course.

The system allows users to:
- Add, update, search, and delete products
- Record sales transactions
- Automatically update stock quantities
- Perform statistical analysis on sales data
- Generate inventory and sales reports
- Save and load data using CSV files

The project is designed using modular programming, where each major component is implemented in a separate Python module.

---

## Features

### Product and Inventory Management
- Create products
- Add products to inventory
- Search for products by ID
- Update product information
- Remove products from inventory
- Save inventory to CSV
- Load inventory from CSV

### Sales Transactions
- Record product sales
- Update stock automatically
- Store transaction history

### Analytics
- Mean
- Median
- Mode
- Variance
- Standard deviation
- Correlation
- Moving average

### Reports
- Inventory report
- Sales report
- Analytics report
